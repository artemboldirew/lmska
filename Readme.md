# LMSKA

Учебная интерактивная LMS на Java. Пока что взаимодействие мозможно только через 
консоль(включать выключать запуск консоли можно через applcation.properties апарметром use-cli)

Кратко по модулям:
1) lmska-core
Все сущности, все сервисы и их имплементации по работе с данными и бд. Также точка входа и основной модуль.
2) lmska-cli 
Модуль взаимодействия с консолью, команды реализованы с помощью паттерна команда. Каждая команда аннотирована @Command 
с префиксом команды и ее описанием
3) lmska-common 
Общие классы для нескольких модулей, пока что только утилсы
4) bring
Модуль реализующий DI для удобства работы приложения, также реализует загрузку конфига. После поднятия контекста
продолжает выполнение пользовательского кода из класса реализующего ApplicationRunner
5) bibernate 
Модуль orm ля работы с базой данных, дает несколько базовых аннотаций. Реализует фабрику классов взаимодействия с бд на основе 
параметра bibernate.db.url из бд, может использовать постгрес и хранилище из модуля b2
6) b2
Модуль для in-memory хранения записей, исполняет sql запросы(но с ограничениями на ключевые слова, напрмиер
обработка GROUP BY, LIKE, HAVING и тд намеренно не добавлена для упрощения реализации)
